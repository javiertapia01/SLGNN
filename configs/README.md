# Configuraciones

- `slgnn_v2/`: entrenamiento general de SLGNN-v2.
- `slgnn_v2/curriculum/`: etapas numeradas S02, S03 y futuras etapas S04.
- `slgnn_v3/`: perfiles de arquitectura de SLGNN-v3.
- `benchmarks/`: benchmarks de dos esferas y transferencia partícula–pared.
- `twin/`: parámetros del banco de pruebas del gemelo digital.
- `experiments/`: protocolos compartidos de comparación v3/GNS.
- `gns/`: configuración específica de los baselines GNS.

Las rutas declaradas dentro de un YAML son relativas a la raíz del repositorio.
